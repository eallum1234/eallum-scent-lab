# EALLUM Scent Design Lab

향수 조향 클래스용 AI 추천 웹앱입니다.

사용자는 감정, 분위기, 공기감, 공간감, 계절감, 잔향 이미지를 단계별로 선택하고 입력합니다. 앱은 `perfume_base_library_63_full.xlsx`에서 변환한 `perfumeBases.json` 데이터만 사용해 추천 어코드와 조향 비율을 계산합니다.

## 1. 앱 실행하기

1. 이 프로젝트 폴더를 엽니다.
2. 터미널을 엽니다.
3. 처음 한 번만 아래 명령어를 입력합니다.

```bash
npm install
```

4. 앱을 켤 때는 아래 명령어를 입력합니다.

```bash
npm run dev
```

5. 터미널에 보이는 주소를 브라우저에서 엽니다. 보통 아래 주소입니다.

```text
http://localhost:5173
```

## 2. 앱 사용 순서

1. 첫 화면에서 `그룹세션을 시작합니다.` 또는 `원데이세션을 시작합니다.`를 누릅니다.
2. STEP 1부터 STEP 6까지 질문에 맞는 카드를 선택합니다.
3. 각 단계에서 떠오르는 감정, 공간, 계절, 이미지를 짧게 적습니다.
4. STEP 7에서 최종 향수 이름을 직접 입력합니다.
5. `추천 결과 보기`를 누릅니다.

## 3. 데이터 규칙

앱은 아래 파일만 데이터베이스로 사용합니다.

```text
public/perfumeBases.json
```

이 파일은 `perfume_base_library_63_full.xlsx`에서 변환한 63개 어코드 데이터입니다.

## 4. 세션 규칙

그룹세션은 지정된 16개 어코드 안에서 최대 5개만 추천합니다.

원데이세션은 63종 전체 어코드를 사용합니다.

원데이세션 추천에는 아래 원칙이 반영되어 있습니다.

- 희귀 어코드도 매칭될 수 있도록 니치 선택지 제공
- 같은 계열만 반복되지 않도록 계열 다양성 점수 적용
- 동점일 때 덜 등장한 어코드를 우선하는 회전 규칙 적용
- 원데이세션에서 니치/개성 어코드 보너스 적용

## 5. 계산 기준

- 30ml 오드뚜왈렛
- 향료 총량 7g
- 추천 비율 합계 100%
- 각 어코드 용량은 `7g × 추천 비율`로 계산

## 6. GitHub Pages 배포 순서

1. GitHub에서 새 저장소를 만듭니다.
2. 이 프로젝트 파일을 저장소에 올립니다.
3. 터미널에서 아래 명령어를 입력해 배포용 파일을 만듭니다.

```bash
npm run build
```

4. GitHub 저장소 화면에서 `Settings`를 누릅니다.
5. 왼쪽 메뉴에서 `Pages`를 누릅니다.
6. 배포 방식을 `GitHub Actions`로 선택합니다.
7. Vite 배포용 GitHub Actions 파일을 추가합니다.

```text
.github/workflows/deploy.yml
```

8. 저장소에 변경사항을 올리면 GitHub Pages에 자동 배포됩니다.

배포 주소는 GitHub Pages 화면에 표시됩니다.
